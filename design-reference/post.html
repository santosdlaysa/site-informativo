Como usar Prisma com PostgreSQL no Next.js

Admin 20 de Maio, 2024 5 min de leitura

O Prisma é um ORM moderno e intuitivo que torna o trabalho com bancos de dados muito mais agradável. Neste post, vamos ver como integrá-lo com PostgreSQL em um projeto Next.js.

1. Instalando o Prisma

Primeiro, instale o Prisma e o cliente:

# instale as dependências
npm install prisma @prisma/client
npx prisma init

2. Configurando o banco de dados

Edite o arquivo .env e adicione sua conexão com PostgreSQL:

DATABASE_URL="postgresql://usuario:senha@localhost:5432/meublog"

3. Criando seu primeiro modelo

Edite o arquivo schema.prisma:

model Post {
  id         Int       @id @default(autoincrement())
  title      String
  content    String
  createdAt  DateTime  @default(now())
}

Pronto! Agora é só rodar as migrations:

npx prisma migrate dev --name init

Com isso seu banco está pronto para uso. A partir daqui você pode importar o cliente do Prisma em qualquer rota da sua aplicação e começar a criar, ler e atualizar registros com poucas linhas de código.
